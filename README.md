# ULTRA Sprint Planner

App di programmazione e monitoraggio per i gruppi sprint di ULTRA Track & Field.

- `public/` — il sito pubblicato da Netlify (pagina unica + collegamento a Supabase)
- `supabase/schema.sql` — tabelle e regole di accesso da eseguire una volta nel SQL Editor di Supabase

Dati e login: Supabase (server in UE, Francoforte). Nessuna libreria caricata da siti esterni: tutto è servito da questo sito.
